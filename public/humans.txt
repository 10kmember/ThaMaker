/* HOW THIS SITE IS BUILT */

   One source of truth: PostgreSQL. Every name on
   this site is there because it is in the
   database, and nowhere else.

   Motion is layered — CSS owns hover and press,
   Motion owns entrances, GSAP owns the scroll
   choreography of a season, Three.js owns the
   trophy. None of the heavy layers load under
   prefers-reduced-motion.

   No tracking. No advertising. No third-party
   embeds. The content security policy says so
   and the code keeps to it.
